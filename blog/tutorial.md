# 从0到1搭建个人博客网站：一个不懂代码的人，如何用 AI 建出自己的网站

## 摘要

一个完全不懂代码的人，如何用 AI 搭建一个属于自己的博客网站？

本教程记录了一次真实的 vibe coding 全过程——只靠打字告诉 AI "我想要什么"，不写一行代码，从零搭建出一个包含前台展示、后台管理、文章发布、评论互动的完整博客网站，并部署上线让任何人都能访问。

同时记录了过程中踩过的 8 个坑，以及用小学生都能听懂的方式解释它们。

---

## 什么是 Vibe Coding？

在开始之前，先解释一个词：**Vibe Coding**。

Vibe 是"氛围、感觉"的意思。Vibe Coding 就是"凭感觉写代码"——你不需要学编程语言，不需要看懂代码，只需要用大白话告诉 AI "我想要什么效果"，AI 就帮你把代码写出来。

你的角色是**产品经理**：提需求、看效果、给反馈。
AI 的角色是**程序员**：写代码、改 bug、部署上线。

这篇教程里，我全程没有写过一行代码。所有代码都是 AI（Claude）完成的。

---

## 最终效果

先看看最终成果，这是搭建完成的博客网站：

- **前台**（所有人都能看）：展示文章列表、文章详情、评论区、分类和标签
- **后台**（只有你能进）：发布文章、管理分类、回复评论、上传图片
- **手机电脑都能访问**：任何人通过链接就能打开

下面开始，一步一步来。

---

## 第一步：准备工作（注册 3 个账号）

搭建网站需要 3 个免费工具，先注册好它们。可以把这三个工具理解成：

| 工具 | 作用 | 生活类比 |
|------|------|----------|
| GitHub | 存放代码 | 你的**文件柜**，所有代码都放在这里 |
| Vercel | 部署网站 | 你的**展示橱窗**，把文件柜里的东西展示给所有人看 |
| Neon | 数据库 | 你的**笔记本**，记录文章内容、用户评论等数据 |

### 1.1 注册 GitHub

1. 打开 https://github.com
2. 点击右上角 **Sign up**
3. 输入邮箱、设置密码、取一个用户名
4. 完成邮箱验证

> GitHub 就像一个代码版的百度网盘。你的网站代码都存在这里，而且是免费的。

### 1.2 注册 Vercel

1. 打开 https://vercel.com
2. 点击 **Sign Up**
3. 选择 **Continue with GitHub**（直接用刚注册的 GitHub 账号登录）
4. 授权 Vercel 访问你的 GitHub

> Vercel 就像一个自动化的网站发布器。你把代码放到 GitHub，Vercel 就自动帮你把它变成一个网站。不需要你买服务器、配域名，它全包了。

### 1.3 注册 Neon

1. 打开 https://neon.tech
2. 点击 **Sign Up**
3. 同样选择用 GitHub 账号登录
4. 创建一个项目，名字随便填（比如 `my-blog`）
5. Region（地区）选默认的就行

> Neon 是一个云端数据库。你发布的每篇文章、读者留的每条评论，都存在这个"笔记本"里。它是免费的，小博客完全够用。

注册好这三个账号后，准备工作就完成了。

---

## 第二步：创建博客项目

现在我们要让 AI 帮我们创建博客网站的代码。

### 2.1 打开 AI 工具

我使用的是 **Claude**（Anthropic 出品的 AI 助手）。你也可以用其他 AI 编程工具，比如 Cursor、GitHub Copilot 等。

### 2.2 告诉 AI 你想要什么

直接用大白话描述你的需求。我当时是这样说的：

> "我想搭建一个个人博客网站，要求有前后台。前台负责展示内容，支持评论留言。后台负责文章增删改查，回复用户评论。网站样式简约美观，参考苹果网站的设计风格。"

就这么简单，一句话。AI 就开始帮你写代码了。

### 2.3 AI 做了什么？

AI 会自动帮你：

- 创建整个项目的文件结构
- 写前台页面（首页、文章详情、分类、标签、关于）
- 写后台管理页面（仪表盘、文章管理、分类管理、评论管理）
- 写登录系统（保护后台只有你能进）
- 设计整体样式（简约、好看、支持暗色模式）
- 配置数据库（定义文章、评论、分类、标签等数据结构）

你什么都不用做，等 AI 写完就行。

### 2.4 把代码上传到 GitHub

AI 会帮你把写好的代码推送到 GitHub。如果 AI 没有自动操作，你可以告诉它：

> "帮我把代码推送到 GitHub"

推送完成后，打开你的 GitHub 页面，就能看到项目代码了。

---

## 第三步：部署上线

代码写好了，存到 GitHub 了，现在让它变成一个真正的网站。

### 3.1 在 Vercel 导入项目

1. 打开 https://vercel.com/dashboard
2. 点击 **Add New** → **Project**
3. 找到你的博客项目（比如 `my-blog`），点 **Import**
4. 直接点 **Deploy**，不需要改任何设置

Vercel 会自动读取 GitHub 上的代码，帮你构建和部署。大约等 1-2 分钟。

### 3.2 配置数据库

部署完成后，你会发现网站打开是白屏或报错。别慌！因为还没有连接数据库。

1. 在 Vercel 项目页面，点左侧的 **Storage**
2. 找到 Neon 数据库（或者新建一个），连接到项目
3. 它会自动把数据库地址添加到项目的环境变量里

> 环境变量是什么？可以理解为"网站的通讯录"。网站需要知道数据库的地址才能读写数据，环境变量就是告诉网站"数据库在这里"。

### 3.3 初始化数据

数据库连接好了，但里面还是空的。需要初始化一下：

1. 在浏览器里访问 `你的网址/api/seed`
2. 页面会显示"Seed complete"
3. 这一步会创建一个管理员账号和一些测试数据

### 3.4 完成！

现在你的网站已经上线了！你会得到一个类似这样的网址：

```
https://你的项目名.vercel.app
```

任何人在任何设备上，输入这个网址就能看到你的博客。

---

## 第四步：进后台写文章

### 4.1 登录后台

1. 在浏览器访问 `你的网址/admin`
2. 输入管理员账号：
   - 邮箱：`admin@blog.com`
   - 密码：`admin123`
3. 点击登录，进入后台管理页面

### 4.2 后台长什么样？

后台左侧是导航菜单：

- **仪表盘**：显示文章数、评论数、阅读量
- **文章**：管理所有文章（新建、编辑、删除、发布/草稿切换）
- **分类**：管理文章分类（比如"技术"、"生活"）
- **评论**：查看和回复读者的评论

### 4.3 写你的第一篇文章

1. 点击左侧 **文章** → 右上角 **写文章**
2. 填写：
   - **标题**：你的文章标题
   - **封面图**：点击上传区域选择一张本地图片（也可以粘贴图片链接）
   - **分类**：从下拉菜单选一个
   - **正文**：写文章内容，支持 Markdown 格式
3. 点 **发布** 按钮

刷新前台首页，你刚写的文章就出现了。

### 4.4 什么是 Markdown？

Markdown 是一种简单的排版格式，用符号来表示标题、加粗、列表等。你不需要学很多，记住这几个就够了：

```
# 大标题
## 小标题
**加粗的字**
- 列表项1
- 列表项2
> 引用的话
```

写出来就会自动变成漂亮的排版。

## 第六步：踩坑记录

以上步骤看起来很简单，但实际操作中，我踩了不少坑。下面把每个坑都记录下来，如果你跟着做也遇到了，直接按方法解决就行。

---

### 坑1：新版工具不兼容

**现象：** 网站构建报错，一堆看不懂的英文错误。

**用大白话解释：** 就像你买了一个最新款的 Type-C 充电器，结果你的手机只支持老款的 Micro-USB 接口，插不进去。工具太新了，和其他零件配不上。

**怎么解决：** 把工具（Prisma）从最新的 7 版本换回稳定的 6 版本。就像换回老款充电器，虽然不是最新的，但能用。

---

### 坑2：数据库在云端用不了

**现象：** 本地测试一切正常，部署到网上就报错。

**用大白话解释：** 你把日记本放在家里的抽屉里，在家写日记没问题。但是你搬到公司去上班了，想翻日记本，发现它还在家里的抽屉里呢——你够不着。本地数据库（SQLite）就是那个"放在家里的日记本"，部署到云端后它不跟着你走。

**怎么解决：** 换成云端数据库（Neon）。就像把纸质日记本换成手机上的备忘录 App，走到哪都能用。

---

### 坑3：环境变量名对不上

**现象：** 数据库明明配好了，网站还是说找不到数据库。

**用大白话解释：** 你给同学传纸条说"告诉小明放学等我"，但班上根本没有叫"小明"的人——人家叫"小王"。代码里写的数据库名字和实际配置的名字不一样，互相找不到对方。

**怎么解决：** 把名字统一。代码里写的名字要和 Vercel 上配置的环境变量名字一模一样。

---

### 坑4：登录成功但进不去后台

**现象：** 输入正确的账号密码，点了登录，但还是停在登录页面，进不去后台。

**用大白话解释：** 你拿着正确的钥匙去开门，钥匙插进去了也转动了，但门就是打不开。为什么？因为门锁里少装了一个零件。密码验证通过了，但系统缺少一个叫 `secret` 的配置，没法生成"通行证"（会话令牌），所以你进不去。

**怎么解决：** 给登录系统补上那个缺失的 `secret` 配置，门锁零件齐了，钥匙就能正常开门了。

---

### 坑5：侧边栏能看不能点

**现象：** 后台管理页面打开了，左边的菜单栏也显示出来了，但是点"文章"、"分类"、"评论"完全没反应。

**用大白话解释：** 你面前有一排按钮，看得清清楚楚，但你怎么按都没反应。就像自动售货机的按钮上面贴了一层透明玻璃——你以为自己按到了，其实手指碰到的是玻璃。代码里有两层组件叠在一起，上面那层"透明的"把下面的按钮点击事件挡住了。

**怎么解决：** 把那层"玻璃"拿掉，重新整理代码结构，让按钮直接暴露出来能被点到。

---

### 坑6：发了文章前台看不到

**现象：** 在后台成功发布了一篇文章，后台文章列表里也能看到，但是刷新前台首页，新文章就是不出来。

**用大白话解释：** 你拍了一张全家福挂在客厅墙上。后来家里添了一个新成员，但墙上的照片还是旧的——因为那是之前拍的照片，不是实时直播。网站也一样，它把第一次加载的页面"拍了张照片"存起来（这叫缓存），之后每次访问都给你看这张旧照片，不会去数据库查最新数据。

**怎么解决：** 告诉网站"别用照片了，每次都给我看实时画面"。加一行代码让页面每次都从数据库读取最新数据。

---

### 坑7：文章详情页打不开

**现象：** 首页能看到文章列表，但是点进任何一篇文章，都显示 404（页面不存在）。

**用大白话解释：** 你在网上买了东西，快递单上的地址写了中文"幸福路123号"。但快递系统只认英文和数字，它看到中文就懵了，找不到地址，包裹就退回去了。文章的链接地址（slug）里包含中文字符，浏览器在传输时把中文变成了一串乱码，数据库就找不到对应的文章了。

**怎么解决：** 把文章的链接地址改成纯英文和数字。就像快递单上写 "xingfu-road-123" 代替 "幸福路123号"，快递员就能准确送达了。

---

### 坑8：代码推了但网站没变化

**现象：** 修复了 bug，代码也推送了，但网站上还是老样子，bug 还在。

**用大白话解释：** 你写好了作业，要交到老师的收作业箱里。但你们学校有很多班级，每个班都有自己的收作业箱。你不小心把作业交到了隔壁班的箱子里，你们班老师打开箱子一看——空的，当然看不到你的作业。代码推送到了一个"练习用的分支"，但 Vercel 只看"正式分支"（main）里的代码。

**怎么解决：** 把代码推送到正确的分支（main）。就像把作业放进自己班级的收作业箱，老师就能看到了。

## 总结

回顾整个过程：

1. 注册了 3 个免费账号（GitHub、Vercel、Neon）
2. 用一句话告诉 AI 想要什么样的博客
3. AI 自动写完了所有代码
4. 点几下按钮就部署上线了
5. 踩了 8 个坑，每个都解决了

**全程没有写过一行代码。**

这就是 Vibe Coding 的魅力：你不需要成为程序员，你只需要会说话、会描述你想要的东西。AI 来负责把它变成现实。

当然，这个过程并不是完全顺利的。正如你在"踩坑记录"里看到的，有些问题对技术小白来说还是有门槛。但随着 AI 工具越来越成熟，这些门槛会越来越低。

也许在不远的将来，搭建一个网站真的就像发一条朋友圈一样简单。
